# 输入框与动效约定

这个博客以阅读为主。交互应有反馈，动效应解释状态变化，同时让文字保持视觉中心。

## 研究参考

阅读与核对日期：2026-11-03。以下为官方范式，具体尺寸与颜色由本项目决定。

- [Carbon — Motion](https://www.carbondesignsystem.com/building-blocks/foundations/motion/overview)：日常交互使用克制的 productive motion；进入、退出、状态变化使用不同缓动；动效应有目的、及时、少干扰，并为减少动态效果的用户提供替代。
- [Adobe Spectrum — Search field](https://spectrum.adobe.com/web/rsp/components/search-field)：搜索框包含搜索图标、可访问的标签、输入内容及清空操作；区分默认、悬停和焦点状态；无结果给出状态提示。

## 本项目的取舍

输入框采用单一表面。边框、背景和焦点反馈由 `.search-field` 承担，内部 input 不再绘制第二层边框。容器圆角 14px，弹窗圆角 20px，手机弹窗为 18px。全局焦点规则不修改圆角，避免覆盖组件形状。

焦点使用中性色边框加低透明度柔光，适配明暗主题；保留键盘焦点可见性。Spectrum 示例使用蓝色焦点环，本项目根据博客的视觉风格改用中性色，未照搬品牌色。标签常驻，placeholder 仅作输入提示，正文输入字号 16px。

动效使用统一变量，优先改变 opacity 与 transform，不动画化布局尺寸。

| 场景 | 时长 | 行为 |
| --- | --- | --- |
| 按钮、焦点与悬停 | 150ms | 颜色平滑变化；图标按钮按下缩至 94% |
| 弹窗进入 | 240ms | 淡入，上移 10px，缩放从 98.5% 归位 |
| 弹窗退出 | 150ms | 淡出，下移 6px；退出结束后关闭原生 dialog |
| 搜索结果 | 180ms | 淡入，上移 4px，不逐条延迟 |
| 页面主要内容 | 320–360ms | 初次渲染淡入，上移 8px，无滚动触发与长时间错峰 |

缓动采用 Carbon 的 productive 曲线：standard `(0.2, 0, 0.38, 0.9)`、entrance `(0, 0, 0.38, 0.9)`、exit `(0.2, 0, 1, 0.9)`。时长根据本页面的移动距离选定。

## 交互实现

- 原生 dialog 保持模态、焦点约束及关闭后的焦点恢复。支持 `/` 打开、Esc / 关闭按钮 / 点击遮罩关闭。
- 输入后 180ms 防抖；中文输入法组词期间不发起搜索。新查询立即清除旧结果，异步结果通过 requestId 防止过期响应覆盖当前查询。
- 清空后恢复输入焦点；上下方向键在结果链接与输入框之间移动；保留标准 Tab 与 Enter 操作。
- `prefers-reduced-motion: reduce` 下关闭动画与平滑滚动，弹窗立即关闭；不依赖动画事件才能完成操作。
- 搜索无结果、加载与失败均有文本反馈；结果加载时设置 `aria-busy`。

后续验收应包含明暗主题、390px 宽屏、键盘操作、中文输入法和减少动态效果设置。避免使用 `transition: all`、循环装饰动画和修改全局 `:focus-visible` 圆角。

- 使用 Go 构建后端服务、CLI 工具与跨平台应用
- 探索 A2A、Eino、工具调用和上下文工程等 Agent 技术
- 开发 AI PR Review，让代码审查能够理解完整仓库与团队规则
- 学习性能分析、可观测性、服务架构与工程质量实践

## 代表项目

### AI PR Review

面向真实代码仓库的 AI 代码审查工具。它会结合完整仓库上下文、依赖关系和自定义规则，从安全、逻辑、性能、测试、质量与架构等维度分析 Pull Request，并提供 Web Dashboard、SARIF 与 CI/CD 集成。

### Smart Pet

基于 Go、Wails 与大模型能力构建的智能桌宠实验项目，尝试把 Agent 能力、桌面交互和本地应用体验结合起来。

### A2A Agent Demo

基于 a2a-go 与 CloudWeGo Eino 的学习项目，包含天气 Agent Server 和终端 Client，用于理解 Agent2Agent 协议和 Agent 工作流编排。
